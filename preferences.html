Under the hood
  • Every colour, font and corner radius on the site is a CSS custom property. Each style and accent is a small set of overrides on the <html> element, in light and dark versions.
  • A short script in the page head reads your choices before anything is drawn, so you never see the default flash first.
  • Your choices are kept in this browser's local storage. Nothing is sent to a server.
  • Links can carry a view: ?lens=executive opens the executive view, ?style=boardroom&accent=gold&mode=dark a shared look.
  • Plain HTML, CSS and JavaScript, with no frameworks and no build step.
